# Personal website of Andrea Canton

Hi! This is the repository of my personal website.

Built with [Bun](https://bun.sh/) (zero dependencies static site generator)

Requires Bun 1.3.9. Run `bun dev.ts` (or `bun run dev`) for the dev server and `bun build.ts` (or `bun run build`) to build into `dist/`.
